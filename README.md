# Bedrock Beta — GitHub Pages package

Upload the **contents** of this folder to the root of your GitHub repository. Keep index.html at the root.

- `index.html`: application with embedded CSS/JavaScript and rock audio button
- `assets/`: two stone button PNG states; **add your existing `yabba-dabba-doo.mp3` here** (not included)
- `quarry/catalog.js`: fictional materials that populate The Quarry immediately
- `quarry/files/`: downloadable fictional SVG demo assets

For new Quarry items, add a record in `quarry/catalog.js` and upload the matching file under `quarry/files/`. No Java server is required; GitHub Pages serves HTML, CSS, JavaScript, and assets.

All data is fictional. Browser state is local; this is not an authenticated or shared production application.
